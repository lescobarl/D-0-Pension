# Onboarding Video

Place your onboarding intro video here as `onboarding_intro.mp4`.

## Requirements

- **Filename**: `onboarding_intro.mp4`
- **Format**: MP4 (H.264 video, AAC audio)
- **Duration**: 10-30 seconds recommended
- **Content**: A short intro video for the app's onboarding screen
- **Resolution**: 1080x1920 (portrait) recommended for mobile

## Without a video file

If no video file is present, the onboarding screen will show a fallback UI
with the app logo and a "Continue" button instead of the video.
